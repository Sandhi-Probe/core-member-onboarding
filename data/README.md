# Data

The project uses the English derivational portion of MorphyNet:

https://github.com/kbatsuren/MorphyNet/blob/main/eng/eng.derivational.v1.tsv

The notebook downloads the file at runtime. Do not commit the full upstream dataset here.

MorphyNet describes derivational entries using fields including source word, target word, source POS, target POS, morpheme, and affix type. See the upstream README for the authoritative schema and license information.
